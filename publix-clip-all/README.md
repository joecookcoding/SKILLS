# Publix Clip All Skill

A tiny browser-automation skill that clips Publix digital coupons in batches and automatically presses **Load more** until the page is exhausted.

## Quick use

Open:

https://www.publix.com/savings/digital-coupons

Sign in, open DevTools Console, paste the contents of `publix-clip-all.js`, and press Enter.

## Files

- `SKILL.md` — full skill instructions, troubleshooting, and safety notes
- `publix-clip-all.js` — standalone script users can paste directly into DevTools

## Disclaimer

This project is not affiliated with Publix. It simply automates clicking controls already available in the user's own browser session. Publix may change its page markup at any time.
