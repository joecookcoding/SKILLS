# Governance

- Local source repositories own their implementation truth.
- Each Repo Map is reviewed and versioned with its source repository.
- The Mesh is a separate optional Git repository with its own history.
- Mesh imports are append/update operations with provenance, never authority overrides.
- Access differences are represented through visibility and opaque nodes.
- Deletion requires human review or verified source deletion; disappearance alone produces `unresolved` status.
