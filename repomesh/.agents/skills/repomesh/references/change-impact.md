# Change Impact Hints

- package/build manifest → dependencies, commands, runtime
- routes/controllers/handlers → interfaces, consumers, workflows
- models/schemas/migrations → data models, storage, contracts
- compose/Kubernetes/Terraform → deployments, services, ports
- environment examples → configuration names, never values
- tests → expected behavior and verification
- CI workflows → build, test, release, deployment processes
- ownership files → team boundaries and review requirements
- shared types or API specs → cross-repository contract impact
